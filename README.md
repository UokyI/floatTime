# floatTime

一个简约的 Android 桌面悬浮倒计时 App。

## 功能

- 圆形悬浮图标，可拖动到任意位置
- 长按悬浮图标弹出设置弹窗：任务名称 + 定时分钟数（默认 5 分钟）
- 弹窗底部「取消 / 开始」按钮
- 点击开始后：
  - 圆形图标上半部分显示任务名前两个字
  - 下半部分显示秒级倒计时（如 `4:59`）
- 倒计时到达后手机震动提示

## 运行

用 Android Studio 打开本目录即可（首次会自动下载 Gradle 8.2 与 AGP 8.2.2）。

手动命令行构建：

```
gradlew.bat assembleDebug
```

安装到手机后，首次启动需要授予「显示在其他应用上层」权限，然后点击「开启悬浮」即可。

## 说明

- `minSdk 24 / targetSdk 34`
- 使用前台服务保持悬浮窗常驻
- 震动权限 `VIBRATE`，悬浮窗权限 `SYSTEM_ALERT_WINDOW`
